# Папка данных ClipFactory

Здесь программа хранит всё локально. Папки создаются автоматически:

| Папка | Что внутри |
|---|---|
| `downloads/` | основные видео (скачанные и загруженные) |
| `gameplay/` | библиотека геймплея |
| `projects/<id>/episodes/` | готовые части `Part_01.mp4`, субтитры `.ass`/`.srt`, миниатюры |
| `exports/` | ZIP-архивы «Скачать все» |
| `subtitles/cache/` | кэш распознавания речи (видео распознаётся один раз) |
| `models/` | модели Whisper (скачиваются один раз) |
| `temp/` | временные файлы |
| `logs/` | журнал `clipfactory.log` |
| `secrets/` | зашифрованные ключи TikTok (Windows DPAPI) |
| `fonts/` | (создайте сами) свои шрифты `.ttf`/`.otf` для субтитров |

Файл `clipfactory.db` — база данных проектов. Для резервной копии достаточно скопировать всю папку `storage`.
