================================================================
  2. ЗАПУСК И ЗАКРЫТИЕ ПРОГРАММЫ
================================================================

ЗАПУСК
------
  Дважды щёлкните ClipFactory.exe.

  • Откроется чёрное окно «ClipFactory запускается...» — это сама программа.
    НЕ ЗАКРЫВАЙТЕ его, пока работаете (его можно свернуть).
  • Через пару секунд в браузере откроется страница ClipFactory
    (адрес http://127.0.0.1:8765/ — он работает только на вашем компьютере).

  Закрыли вкладку браузера случайно? Снова дважды щёлкните ClipFactory.exe —
  вторая копия не запустится, просто снова откроется страница.


КАК УСТРОЕНА ПРОГРАММА (меню слева)
-----------------------------------
  Главная             — статистика и то, что сейчас обрабатывается
  Новый проект        — создать серию видео из мультфильма   <-- начинайте отсюда
  Мои проекты         — все созданные серии
  Геймплей            — ваша библиотека видео для нижней половины экрана
  Очередь публикаций  — подготовка частей к загрузке в TikTok
  Настройки           — параметры по умолчанию, распознавание речи, TikTok

  Картинка: Инструкции\Картинки\01 Главная.png


ЗАКРЫТИЕ
--------
  Закройте чёрное окно программы (крестик) — ClipFactory остановится.
  Если в этот момент шла обработка, при следующем запуске она
  продолжится с того же места — готовые части заново не делаются.


ГДЕ ЛЕЖАТ МОИ ВИДЕО
-------------------
  • Кнопки «Скачать» в программе сохраняют файлы в обычную папку
    «Загрузки» (Downloads) вашего браузера.
  • Все рабочие файлы программы хранятся в  app\storage\
    (там же готовые части: app\storage\projects\...\episodes\Part_01.mp4).
    Чтобы сохранить резервную копию — скопируйте папку app\storage.
