================================================================
                     ClipFactory — с чего начать
================================================================

ClipFactory делает из целого мультфильма серию вертикальных видео
для TikTok: мультфильм сверху, геймплей снизу, крупные субтитры,
«Часть 1/3», «Часть 2/3»... Всё работает на вашем компьютере, бесплатно.


ЗАПУСК — ДВА ШАГА
-----------------

  1. Дважды щёлкните по файлу  ClipFactory.exe  (он рядом с этим файлом).

  2. Первый раз откроется окно установки (5–15 минут, нужен интернет).
     Когда спросят про FFmpeg — нажмите клавишу Y.
     Когда появится «Установка завершена» — нажмите любую клавишу.

  Программа откроется в браузере сама. В следующие разы просто
  дважды щёлкайте ClipFactory.exe — установка больше не нужна.

  Если Windows покажет синее окно «Windows защитил ваш компьютер»:
  нажмите «Подробнее» → «Выполнить в любом случае». Это обычное
  предупреждение для программ без цифровой подписи.


ЧТО ЗДЕСЬ ЛЕЖИТ
---------------

  ClipFactory.exe   — запуск программы (жмите сюда)
  Инструкции\       — подробные инструкции с картинками «куда жать»
  Пример\           — пример: мультфильм «Закатун» + геймплей и готовые 3 части
  Мои видео\        — удобное место для ваших мультфильмов и геймплея
  app\              — сама программа (ничего внутри трогать не нужно)
