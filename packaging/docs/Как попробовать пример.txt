================================================================
  ПРИМЕР: мультфильм «Закатун» + геймплей → 3 видео
================================================================

Готовый результат уже лежит в папке «Готовый результат» — откройте и
посмотрите 3 части (видео без звука, только субтитры).

Чтобы сделать то же самое самому (за 5 минут):

  1. Запустите ClipFactory.exe → меню «Новый проект».
  2. «1. Основное видео» → «Файл с компьютера» → перетащите
       Пример\Исходники\zakatun.mp4
  3. Нажмите «Загрузить .srt / .vtt» → выберите
       Пример\Исходники\zakatun.srt
  4. «2. Геймплей» → «Файл с компьютера» → перетащите
       Пример\Исходники\obby_gameplay.mp4
  5. Посмотрите блок «Кадрирование» — в автоматическом режиме чёрные полосы
     уберутся, а герой будет в центре кадра в каждой части.
  6. Нажмите «Создать видео». Получится 3 части по 60 секунд.

Мультфильм и геймплей нарисованы программой специально для примера —
их можно использовать как угодно.
