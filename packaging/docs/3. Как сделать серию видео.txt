================================================================
  3. КАК СДЕЛАТЬ СЕРИЮ ВИДЕО (главная инструкция)
================================================================

Итог: из одного мультфильма получается несколько вертикальных видео
1080×1920 по 60 секунд (можно 30, 45, 90 или своё) — мультфильм сверху,
геймплей снизу, крупные субтитры на стыке, «Часть 1/N».
Ни одна секунда мультфильма не теряется и не повторяется.


ШАГ 1. ОТКРОЙТЕ «НОВЫЙ ПРОЕКТ»
------------------------------
  Меню слева → «Новый проект».
  Картинка: Картинки\01 Главная.png


ШАГ 2. ДОБАВЬТЕ МУЛЬТФИЛЬМ
--------------------------
  В блоке «1. Основное видео»:
    • вкладка «Файл с компьютера» — перетащите файл мышью в рамку
      или нажмите на рамку и выберите файл;
    • или вкладка «По ссылке» — вставьте ссылку и нажмите «Загрузить».
  После загрузки появятся превью, длительность, разрешение.
  Картинка: Картинки\02 Новый проект - загрузка видео.png  (отметка 1)


ШАГ 3. ДОБАВЬТЕ ГЕЙМПЛЕЙ
------------------------
  В блоке «2. Геймплей» так же загрузите видео (например, Roblox)
  или отметьте галочкой клип из библиотеки.
  Короткий геймплей сам зациклится. Звук геймплея по умолчанию выключен.
  Картинка: Картинки\02 Новый проект - загрузка видео.png  (отметки 2 и 3)


ШАГ 4 (необязательно). СУБТИТРЫ ИЗ ФАЙЛА
----------------------------------------
  Есть готовый файл субтитров .srt? Нажмите «Загрузить .srt / .vtt».
  Нет файла — ничего не делайте: субтитры создадутся сами из речи.
  Ниже, в блоке «3. Разбивка на части», видно, на сколько частей
  разделится видео.
  Картинка: Картинки\03 Субтитры из файла и разбивка.png


ШАГ 5. ПРОВЕРЬТЕ КАДРИРОВАНИЕ
-----------------------------
  Блок «Кадрирование» показывает, какая часть кадра попадёт в видео.
  «Автоматически» обычно достаточно. Подробнее: «4. Кадрирование.txt».
  Картинка: Картинки\04 Кадрирование.png


ШАГ 6. НАСТРОЙКИ И «СОЗДАТЬ ВИДЕО»
---------------------------------
  • Длительность одной части (по умолчанию 60 сек).
  • Стиль субтитров (по умолчанию «Крупно по слову» — как в популярных
    TikTok-сериях).
  • «Название для подписей» — например «как я Лысым стал», тогда подписи
    будут «как я Лысым стал часть 1», «... часть 2».
  • Нажмите розовую кнопку  «Создать видео»  внизу справа.
  Картинка: Картинки\05 Настройки и кнопка Создать видео.png


ШАГ 7. ДОЖДИТЕСЬ ОБРАБОТКИ
--------------------------
  Откроется страница проекта. Вверху видно, что происходит:
  «Загрузка видео» → «Анализ исходника» → «Распознавание речи» →
  «Автокадрирование» → «Создание части 2 из 3» → «Готово».
  Показаны проценты и примерное оставшееся время. Можно нажать «Отмена».
  Картинка: Картинки\06 Ход обработки.png

  Сколько ждать: на обычном ПК примерно 1–3 минуты на каждую часть,
  плюс распознавание речи (в первый раз дольше — скачивается модель).


ШАГ 8. ПОСМОТРИТЕ, ИСПРАВЬТЕ, СКАЧАЙТЕ
-------------------------------------
  У каждой части свои кнопки:
    «Просмотр»      — посмотреть крупно
    «Редактировать» — исправить текст субтитров, стиль, кадр, геймплей
    «Пересоздать»   — сделать эту часть заново
    «Скачать»       — сохранить MP4
    «Одобрить»      — отметить, что вы проверили часть
  Картинка: Картинки\07 Готовые части.png

  «Скачать все (ZIP)» вверху — все части одним архивом вместе
  с подписями для TikTok.
  Картинка: Картинки\08 Скачать все части.png


ИСПРАВИТЬ ОДНУ ЧАСТЬ
--------------------
  «Редактировать» → вкладка «Субтитры» → исправьте текст →
  «Сохранить и пересоздать». Пересоздаётся только эта часть.
  Картинка: Картинки\09 Редактор части.png


ЗВУК
----
  По умолчанию части БЕЗ ЗВУКА — только субтитры.
  Включить звук оригинала: в настройках проекта переключатель «Звук оригинала».
