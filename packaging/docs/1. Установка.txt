================================================================
  1. УСТАНОВКА (один раз)
================================================================

ЧТО НУЖНО
---------
  • Windows 10 или 11
  • Интернет (только на время установки)
  • Около 3 ГБ свободного места
  • Python 3.11 или новее (бесплатно, см. ниже)


ШАГ 1. УСТАНОВИТЕ PYTHON (если его ещё нет)
-------------------------------------------
  1. Откройте сайт  https://www.python.org/downloads/windows/
  2. Нажмите жёлтую кнопку «Download Python 3.12...» (или новее).
  3. Запустите скачанный файл.
  4. ВАЖНО: в самом первом окне установщика поставьте галочку
         [x] Add python.exe to PATH
     и только потом нажмите «Install Now».
  5. Дождитесь «Setup was successful» и закройте окно.

  Не уверены, есть ли Python? Просто переходите к шагу 2 —
  ClipFactory сам скажет, если Python не найден.


ШАГ 2. РАСПАКУЙТЕ АРХИВ
-----------------------
  1. Правой кнопкой по ClipFactory.zip → «Извлечь все...» → «Извлечь».
     Лучше распаковать в простое место, например  C:\ClipFactory
  2. Не запускайте программу прямо из zip-архива — сначала распакуйте.


ШАГ 3. ЗАПУСТИТЕ ClipFactory.exe
--------------------------------
  1. Дважды щёлкните ClipFactory.exe.
  2. Появится окошко «Похоже, ClipFactory запускается впервые» → нажмите «ОК».
  3. Откроется чёрное окно установки. Оно само:
       [1/5] проверит Python
       [2/5] создаст рабочую папку
       [3/5] скачает библиотеки (самый долгий шаг, 3–10 минут)
       [4/5] проверит FFmpeg — программу для обработки видео.
             Если спросит «Скачать FFmpeg автоматически? [Y - да, N - нет]»,
             нажмите клавишу  Y  (английская буква).
       [5/5] подготовит базу данных
  4. Когда увидите «Установка завершена» — нажмите любую клавишу.
     ClipFactory откроется в браузере.

  Если появилось синее окно «Windows защитил ваш компьютер»:
  «Подробнее» → «Выполнить в любом случае».


ПОСЛЕ УСТАНОВКИ
---------------
  Больше ничего устанавливать не нужно. Каждый раз запускайте
  ClipFactory.exe двойным щелчком.

  При первом создании субтитров из речи программа один раз скачает
  модель распознавания (около 500 МБ). Потом всё работает без интернета.
